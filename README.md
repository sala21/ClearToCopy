# ClearToCopy

**Real-time transcription of ATC (Air Traffic Control) radio communications**, using voice activity detection (VAD), a band-pass filter dedicated to radio speech, and a Whisper model specialized in aviation phraseology — **running entirely locally on GPU** — no audio data leaves the device, no dependency on cloud services at runtime.

## Features

- **Real-time audio capture** from microphone/audio line (PyAudio)
- **Voice Activity Detection** (WebRTC VAD) with configurable parameters, to isolate individual transmissions
- **Band-pass filter** (300–3400 Hz) optimized for VHF radio audio
- **100% local transcription**: the model stays loaded in VRAM for the entire application session; restarting transcription (Stop/Start) does not require reloading it
- **Graphical interface** (Tkinter) with a live transcription panel, runtime metrics, and hot-swappable configuration
- **Metrics**: segments sent/completed/failed, average inference time, dropped audio frames

## Requirements

### Hardware

- NVIDIA GPU with at least **8 GB of VRAM** (tested on RTX 5050 Laptop GPU)
- If the GPU is **Blackwell architecture** (RTX 50 series): updated NVIDIA driver (R570+ series) and PyTorch **2.7.0+** with CUDA **12.8+** build
- Without a compatible GPU, the model can run on CPU, with significantly higher inference times — not recommended for real-time use

### Software

- Python 3.10+
- Windows 10/11 (reference environment)

## Installation

### 1. Clone the repository

\`\`\`bash
git clone https://github.com/sala21/ClearToCopy.git
cd ClearToCopy
\`\`\`

> **Windows + OneDrive:** avoid working from a folder synced with OneDrive. Paths generated by some dependencies (in particular `torch`) can exceed the Windows path-length limit. Clone to a short path, e.g. `C:\dev\ClearToCopy`.

### 2. Create a virtual environment

\`\`\`bash
python -m venv venv
.\venv\Scripts\Activate.ps1         # Windows (PowerShell)
source venv/bin/activate       # Linux/macOS
\`\`\`

### 3. Install PyTorch with CUDA support

**Do this first and separately**, with the build matching your GPU — see [pytorch.org/get-started/locally](https://pytorch.org/get-started/locally/). Example for CUDA 12.8:

\`\`\`bash
pip install torch --index-url https://download.pytorch.org/whl/cu128
\`\`\`

Verify:

\`\`\`bash
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
\`\`\`

Should print `True` followed by the GPU name.

### 4. Install the remaining dependencies

\`\`\`bash
pip install -r requirements.txt
\`\`\`

Includes `transformers` and `accelerate` for local inference, `PyAudio` and `webrtcvad` for capture/VAD, `scipy` for the band-pass filter. `Pillow` is optional: if missing, the application still works, simply without the decorative illustration in the GUI's side menu.

### 5. (Windows) Enable long paths

Recommended to avoid installation errors. In PowerShell as administrator:

\`\`\`powershell
New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force
\`\`\`

Restart the PC after making the change.

## Quick Start

\`\`\`bash
python gui_main.py
\`\`\`

The model loads automatically when the window opens (up to ~1 minute the first time); the **▶ START** button becomes active once loading finishes. For full details on using the interface, see the [User Manual](docs/user_manual.md).

For command-line use, without a graphical interface:

\`\`\`bash
python main.py
\`\`\`

## Configuration

All settings are found in `config.json`, editable by hand or from the GUI's configuration window. Quick reference:

| Section | Content |
|---|---|
| `local_model` | Whisper model, device, language, generation parameters |
| `audio` | Sample rate, channels, frame duration |
| `vad` | Voice activity detector sensitivity and timing |
| `filter` | Pre-transcription band-pass filter |
| `debug` | Logging level |
| `radio` | Reserved for an alternative segmentation mode, **not yet implemented** — see [Technical Manual](docs/technical_manual.md#-schema-di-configjson) |

Full documentation of every field in the [Technical Manual](docs/technical_manual.md#-schema-di-configjson).

## Known Limitations

- **Partial hot-reload**: VAD, filter, and some generation parameters update on the fly; changing model or device requires closing and reopening the application.
- **Serial inference**: one segment at a time, for compatibility with GPUs with limited VRAM.

Full list, including a few minor code inconsistencies to keep in mind during maintenance, in the [Technical Manual](docs/technical_manual.md#-note-di-manutenzione-e-problemi-noti).
